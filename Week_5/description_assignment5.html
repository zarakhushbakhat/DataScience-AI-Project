Step 2: Preprocessing

  • Handle missing values: Fill missing numeric values with median.
  • Encode categorical variables:
    • Only encode low-cardinality categorical columns (less than 20 unique values).
    • Use one-hot encoding (pd.get_dummies) and avoid creating too many dummy columns to prevent memory errors.
  • Result: Clean, numeric-only dataset ready for regression.

Step 5: Build Linear Regression Model

  • Use sklearn.linear_model.LinearRegression to train the model on the training set.
  • Linear Regression formula:
    • y = β0 + β1*x1 + β2*x2 + ⋯ + βn*xn

    Where:

    • y = predicted target (CSAT Score)
    • xi = features
    • βi = coefficients (effect of each feature on CSAT Score)
    • β0 = intercept

Step 6: Predict on Testing Set

  • Calculate predicted CSAT scores: y_pred = model.predict(X_test)
  • Calculate residuals: residual = y_test - y_pred

Model Evaluation Metrics (Manual Calculation)

Formulas used:

  • MAE (Mean Absolute Error) = (1/n) Σ |yi - ŷi|
  • MSE (Mean Squared Error) = (1/n) Σ (yi - ŷi)²
  • RMSE (Root Mean Squared Error) = √MSE
  • Explained Variance = 1 - var(residuals) / var(ytest)

Step 7: Evaluate Model

  • MAE (Mean Absolute Error): Average absolute difference between predicted and actual values
    MAE = (1/n) Σ |yi - ŷi|
  • MSE (Mean Squared Error): Average squared difference
    MSE = (1/n) Σ (yi - ŷi)^2
  • RMSE (Root Mean Squared Error): Square root of MSE
    RMSE = √MSE
  • Explained Variance: How much variance of target is explained by model
